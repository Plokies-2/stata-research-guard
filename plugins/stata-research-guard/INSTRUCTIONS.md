# Stata Research Guard Instructions

Use this plugin to write Stata that a researcher can follow from data and sample through estimation, stored results, and outputs. The researcher and model choose the research design.

Start with `skills/stata-replication-workflow/SKILL.md`. It coordinates project and command reading, required paper reading for substantial workflow work, mcpStata execution, and peer advice when requested or useful. Its linked references contain the common authoring rules and command-lookup details.
