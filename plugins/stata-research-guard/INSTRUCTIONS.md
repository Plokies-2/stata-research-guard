# Stata Research Guard Instructions

Use this plugin to write Stata that a researcher can follow from data and sample through estimation, stored results, and outputs. The researcher and model choose the research design.

Start with `skills/stata-replication-workflow/SKILL.md`. Read the active project code and its affected output first. Use Guard for material command evidence, and consult connected paper code when requested or when a concrete implementation choice benefits from an example. Execute through an available authorized Stata interface and use read-only peer advice when requested or useful for the research question. Load only the references the current work needs.
