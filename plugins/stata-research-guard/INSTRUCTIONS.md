# Stata Research Guard Instructions

Use this plugin to write Stata that a researcher can follow from data and sample through estimation, stored results, and outputs. The researcher and model choose the research design.

Start with `skills/stata-replication-workflow/SKILL.md`, the single research-workflow entrypoint, and identify what changes before loading references or calling Guard. Interface-preserving moves and formatting need a local patch and affected-output check; research or command-interface changes need relevant evidence. The skill coordinates substantial paper reading, execution through an available authorized Stata interface, and one independent reading for substantial analysis changes, with small-edit exceptions. This plugin does not bundle or require mcpStata. Load execution guidance and other linked references only for the current need and reuse visible unchanged evidence.
