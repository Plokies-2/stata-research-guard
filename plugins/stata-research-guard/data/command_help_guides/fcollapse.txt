Title

    fcollapse -- Efficiently make dataset of summary statistics

Syntax

        fcollapse clist [if] [in] [, options]

    where clist is either

        [(stat)] varlist [ [(stat)] ... ]

        [(stat)] target_var=varname [target_var=varname ...] [ [(stat)] ...]

    or any combination of the varlist or target_var forms, and stat is one of

        mean         means (default)
        median       medians
        p1           1st percentile
        p2           2nd percentile
        ...          3rd-49th percentiles
        p50          50th percentile (same as median)
        ...          51st-97th percentiles
        p98          98th percentile
        p99          99th percentile
        sum          sums
        count        number of nonmissing observations
        percent      percentage of nonmissing observations
        max          maximums
        min          minimums
        iqr          interquartile range
        first        first value
        last         last value
        firstnm      first nonmissing value
        lastnm       last nonmissing value
        nansum       same as sum, but if all obs. in the group are missing it will also be missing (instead of zero)
        rawstat      compute stats while ignoring weights (a generalization of rawsum)

    If stat is not specified, mean is assumed.

    Technical limitation: Both normal stats and raw stats will ignore zero weights

    options          Description
    ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
    Options
      by(varlist)    groups over which stat is to be calculated
      merge          merge collapsed dataset back into the original one; if the dataset is unsorted or sorted by something different than by(), it is much more efficient than egen and that combining collapse with merge
      append         append collapsed dataset at the end of the original one; this is useful to create rows of totals
      cw             casewise deletion instead of all possible observations
      fast           do not preserve and restore the original dataset; saves speed but leaves the data in an unusable state shall the user press Break
      smart          invoke collapse if the data is already sorted (in which case collapse might be faster)
      freq[(newvar)] store the raw observation count (similar to contract).  If not indicated, the name of the new variable will be _freq
      register(keys) add new stat functions.  For each key, a corresponding Mata function should exist.  See example at the end
      pool(#)        load the data into stata in blocks of # variables Default is pool(.), select a low value (pool(5)) or very low value (pool(1)) to save memory at the cost of speed
      nocompress     compress chooses the most compact variable type, at a small speed cost (on by default)
      verbose        display misc. debug messages

    ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------


Description

    fcollapse converts the dataset in memory into a dataset of means, sums, medians, etc.  clist can refer to numeric and string variables although string variables are only supported by a few functions (first, last, firstnm, lastnm).

    Weights are only partially supported.

    You can implement your own Mata functions to easily extend the fcollapse command.


Options

        +---------+
    ----+ Options +------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

    by(varlist) specifies the groups over which the means, etc., are to be calculated.  If this option is not specified, the resulting dataset will contain 1 observation.  If it is specified, varlist may refer to either string or numeric variables.

    merge works similarly to egen.  It will collapse the data in Mata and then add it back to the original dataset.  If the dataset is not sorted by the groups set in by(), this is much faster than egen and collapse followed by merge.

    cw specifies casewise deletion.  If cw is not specified, all possible observations are used for each calculated statistic.

    fast specifies that fcollapse not restore the original dataset should the user press Break.

    freq stores frequencies on a new variable _freq.  To choose the name of the variable, use freq(newvar)

    register(fun1 ...) registers Mata functions fun1, etc. so to extend {cmd fcollapse}; see example below.

    pool(#) load the data into Stata in blocks of # variables Default is pool(.), select a low value (pool(5)) or very low value (pool(1)) to save memory at the cost of speed.

    compress will fit variables into more compact types, such as byte, int, and long, without losing information when compared to more accurate types such as double.  The cost is a slight reduction in speed, due to the extra checks involved.

Example: Adding your own aggregation functions

The following code adds the stat. variance:


    sysuse auto, clear

    cap mata: mata drop aggregate_variance()
    
    mata:
    mata set matastrict on
    transmorphic colvector aggregate_variance(
        class Factor F,
        transmorphic colvector data,
        real colvector weights)
    {
        real scalar i
        transmorphic colvector results
        results = J(F.num_levels, 1, missingof(data))
        for (i = 1; i <= F.num_levels; i++) {
            results[i] = quadvariance(panelsubmatrix(data, i, F.info))
        }
        return(results)
    }
    end
    
    fcollapse (mean) price (variance) weight foreign, by(turn) register(variance) freq
    li


Note that the to create a new stat variance we created a Mata function
called aggregate_variance. To avoid overlap with other Mata functions,
your function must start with aggregate_.
